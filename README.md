# Day 016｜長文→スレッド分割ツール

> 100日100プロダクトチャレンジ Day 016（2026-08-22）／カテゴリ: SNS補助ツール

## これは何か

長文を貼り付けると、140字以内のポストに自動で分割して連番を付け、1件ずつコピーできるツール。

## 解決する困りごと

- 想定利用者: SNS（X）に長文の考えを投稿したいが、140字制限のために自分で数えながら文章を切っている個人事業主・フリーランス・情報発信者
- 困りごと: 「書きたいことが140字に収まらず、毎回自分で数えながら手作業で区切っている」
- 解決方法: 長文を貼り付けると、句点・改行のうち140字境界に近い方を優先して自動的に140字以内に分割し、連番付きで1件ずつコピーできるようにする

## 使い方

```bash
# ブラウザでindex.htmlを開くだけ（ビルド不要）
```

1. テキストエリアに長文を貼り付ける
2. 「分割する」ボタンを押す
3. 分割された各ポスト（連番付き）を「コピー」ボタンで1件ずつコピーする

## 主な機能

- 機能1: 句点（。）・改行のうち140字境界に近い方を優先して140字以内で分割する貪欲法（どちらも見つからない場合のみ140字で強制的に区切る）
- 機能2: 分割した各ポストへの「(1/n)」形式の連番表示
- 機能3: 各ポストの個別コピーボタン（`navigator.clipboard.writeText`、非対応環境向けフォールバックあり）

## 使用技術

- フレームワーク: なし
